# TEACH PACK 001 — AGY fundamentals for Muse

## Objective

Teach Muse enough AGY protocol to complete unseen delegation tasks with minimal rework.

## Lessons

### L1 Source-of-truth
When memory/chat conflicts with newer Drive/runtime evidence, use newer Drive/runtime. Preserve the conflict in evidence.

### L2 State transitions
Prompt sent = INSTRUCTED, not PASS. Executor ACK = receipt, not execution. Test output = TESTED, not automatically INTEGRATED.

### L3 Worker feedback
Return exact blocker class. Do not count route/spec/context failure as model incompetence.

### L4 Routing
Capability/quality first, resource efficiency second, QA third, adaptive learning thereafter. Muse and ChatGPT are same priority tier when both eligible.

### L5 QA
QA1 self-check + peer QA + deterministic QA where possible. Critical false PASS must be zero before promotion.

### L6 Handoff
Return a continuation packet another worker can use without rereading the whole conversation.

### L7 Learning
Convert failures into: observed failure -> root cause -> corrected rule -> counterexample -> unseen transfer case. Do not promote from explanation alone.

## Comprehension check

Muse must produce:
1. a normalized contract for an unseen task;
2. a blocker response for a missing route;
3. a peer-QA checklist;
4. a handoff packet;
5. one counterexample proving it distinguishes INSTRUCTED from PASS.

All five are graded by `evals/EVAL-PROTOCOL.md`.
