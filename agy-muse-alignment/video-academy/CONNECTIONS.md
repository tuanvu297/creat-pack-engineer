## Ready-to-connect boundary

The eventual AGY connector must have a real HTTPS endpoint, supported API/MCP transport, server-bound project identity and documented scopes. Do not paste a guessed /mcp URL from the old staging REST server. Use connector/contract.json and prompts/CONNECTION-HANDOFF.md when the actual eligible implementation exists.

The owner clicks Connect/Install/consent; retain progress and test the exact selected tools. A skills-only plugin can carry education but cannot create a personal Muse execution endpoint or bypass account region/permission controls.
