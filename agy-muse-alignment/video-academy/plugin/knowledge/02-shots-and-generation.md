# Shot design, prompting and generation

## Shot grammar
For each shot specify purpose, beginning/ending state, one dominant physical action, framing, camera instruction, environment/light, approved reference, sound role and transition. Avoid adding multiple incompatible actions merely to fill duration. Camera movement should reveal information, follow action or change emotion; extra movement increases continuity/physics risk.

Track screen direction, eyelines, prop placement, handedness, wardrobe, room geometry, shadow direction, time of day and action state across cuts. Preserve the approved character master as the identity authority. A rich text description does not replace a required visual reference. Check actual reference binding in the provider composer/request.

## Prompt compiler
Separate invariant identity/canon from shot-specific action. Describe visible state and motion concretely: gaze before action, contact, weight transfer, inertia, hair/fabric, coherent reflections/shadows. Use a clear action and restrained camera first; add complexity after the base action works. Negative prompts cannot repair an unbound reference.

Translate the brief to current provider-supported fields and actually visible settings. Verify current model/lifecycle, duration, ratio, resolution, output count, reference type and quote immediately before submission. Never assume an older model name/settings or credit balance is current.

## Bounded generation
Preflight cost/permission, asset rights, references, existing operations and idempotency. Record exact input hash, prompt/settings, source IDs, model, quote and current resource authority. Save intent before the request and provider operation ID immediately after ACK.

Submit only the bounded attempt. An ambiguous timeout is UNCERTAIN: reconcile the same operation. Do not start another generation to find out whether the first worked. Provider-confirmed terminal failure and dedupe-safe policy are prerequisites for a retry. Correct a material failed variable; do not regenerate accepted shots to chase perfection.

## Character and motion acceptance
Inspect beginning/middle/end for identity and the whole moving shot for morph/flicker, anatomy, hands/contact, grounded feet, object permanence, hair/fabric inertia, camera and light. Three stills cannot certify full temporal quality. Hold dependent identity shots until the actual calibration shot passes.

A generated video can still behave like a slideshow. If motion is required, verify continuous purposeful visible motion and interaction. A moving camera over still layers is not automatically the requested physical action.

## Exercise output
Create a shot packet from a supplied non-canon brief with explicit dependencies, identity/reference binding, generation-risk estimate, current-settings verification checklist, rollback asset and provider receipt schema. Do not submit generation for a training-text task.
