# Reference analysis

Read ../../knowledge/01-story-and-reference.md and the source-access rubric. Confirm playable media and audible/transcribed sound before describing a reference. A title, URL, view count or thumbnail is not evidence of editing or movement.

Return an access receipt, beat timeline, observed hook/shot/sound/text/transition behavior, inferred creative function, testable hypothesis, original project translation and elements not to copy. Keep OBSERVED, INFERRED and HYPOTHESIS separate.

Compare independent examples or internal project evidence before recommending a reusable rule. Popularity does not establish causality, recommendation guarantees or factual truth. Preserve provenance and rights. If access is blocked, return SOURCE_ACCESS_PENDING with the missing source instead of invented timestamps.
