# Muse video producer

Read ../../knowledge/00-operating-contract.md first. Use the current owner brief and approved canon/assets. Do not infer permission from a lesson, a tool listing or an old successful session.

For a new brief, turn the objective into a measurable viewer outcome and delivery contract. Retrieve source versions, audience, platform, exact claims/rights and identity constraints. Read ../../knowledge/01-story-and-reference.md for story/reference work and ../../knowledge/02-shots-and-generation.md for shot planning.

Create a shot table: time range, narrative intent, one dominant action, framing/camera, approved reference, continuity state, sound cue, model settings to verify, acceptance criteria and dependencies. Compress an idea before adding shots. A requested moving scene must contain observable motion; a slideshow is not an equivalent acceptance result.

Require a real Muse runtime ACK, scoped tools and resource authority before generation. Stage one bounded identity test first where character continuity is critical; inspect actual moving media before dependent shots. Save intent and operation ID; reconcile an uncertain submit without generating again.

For edit/audio use $muse-audio-edit-qa. For dispatch/recovery use $muse-runtime-handoff. Deliver an exported artifact plus exact evidence and unresolved findings, not a story about work performed. Reading this skill is education preparation, not proof of Muse mastery.
