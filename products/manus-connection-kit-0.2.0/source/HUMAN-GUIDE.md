# Manus Connection Kit — Easy Human Mode 0.2.0-human.1

Windows x64 private pilot. Receive exactly **START-HERE.html** and **Manus-Connection-Kit-Setup.exe** in the consumer ZIP. The installer includes its Python/Tk runtime; no Python installation, terminal, PowerShell command, administrator permission or paid dependency is required for normal setup.

1. Read START-HERE.html. Obtain this release through the owner's trusted channel. This pilot EXE is unsigned; a matching SHA-256 verifies the expected file only when the expected hash arrives through a separately trusted channel. Do not override Windows or organization security policy. A blocked unsigned executable is an explicit pilot limitation.
2. Double-click the EXE. Select **1. Install / Update**. It installs only for your Windows account, under `%LOCALAPPDATA%/ManusConnectionKit/human/current/ManusConnectionKit.exe`. Use **Open Installed App Folder**, then reopen that installed EXE (or the original setup EXE) whenever you need this panel. The installer does not start a service, configure a firewall, download code, or silently update itself. The `human` directory coexists with AI Mode's separate `ai` directory.
3. Enter your own Manus API key in the masked local field, then select **2. Save Key**. The field clears after saving. The key is encrypted with Windows DPAPI CurrentUser at `%LOCALAPPDATA%/ManusConnectionKitState/api-key.dpapi`. It is never written to an environment variable, registry, chat, report, config JSON, or log. The Windows session necessarily holds it briefly in process memory. Protect your account; software running as your account can use your stored key. Do not send the key to support.
4. Select **3. Test Connection**. This performs one read-only `user.me` request to Manus, with no automatic retry and no created task. **PASS — AUTH_VERIFIED** means the account was read successfully during that click. **BLOCKED — API_KEY_REQUIRED** means save a key first. **BLOCKED — PROVIDER_HTTP_401/403** means check your key/account. A transport error is uncertain: check your connection and deliberately test again when ready. Offline installer self-test does not prove live authentication.
5. Select **Create AI Client Connection File**, choose where to save `manus-mcp.json`, then import it in a local AI client supporting MCP stdio. The JSON contains only executable/state paths. Clients differ in where they import MCP configuration; automatic client editing has not been proved. Reopening the panel and saving a connection file needs no terminal.

The local connection works only when the installed app is launched by a compatible local client. Ordinary ChatGPT/Claude/Gemini web chat has no proven bridge to this local Kit. No such compatibility is claimed. Creating/resuming/stopping Manus tasks still requires a fresh owner-authorized external grant bound to the same journal; no private owner grant, authority key or live journal is included. A controller may add `--grant` plus the external grant path in its MCP config. This security boundary is not removed by saving an API key. The legacy core reports its preserved adapter version 0.1.1; the GUI/distribution version is 0.2.0-human.1.

## Updates, rollback and uninstall

Updates are assisted and explicit. Obtain the new setup EXE and its expected SHA-256 from a trusted release channel. Open the new setup EXE, select **Install / Update**, review its displayed version and paste the expected hash when replacing a different installed executable. The installer refuses a mismatched or absent update checksum, tests the candidate offline, saves the previous executable and hash, activates the candidate, and runs its offline self-test again. A failed activation restores the previous executable. No background update mechanism exists. A checksum is not a publisher signature. Automated online version checking is not provided in this offline pilot; compare the visible version with the owner's release receipt.

**Rollback** verifies the saved backup hash and offline test before replacing the app. Close connected AI clients first. **Uninstall** removes owned app binaries and installation metadata, keeping the private journal and saved key outside the app directory so pending provider operations remain reconcilable. **Remove Saved Key** explicitly deletes the encrypted key. Uninstall does not stop remote tasks or delete provider records. Keep this panel open to remove your key before uninstalling if desired. Maintenance launched from the installed EXE starts a temporary helper and closes the panel to release Windows file locks; a temporary helper EXE may remain in the Windows temporary directory until normal OS cleanup.

## Limits and minimum owner actions

License, support terms and code signing remain unresolved, so this is not a commercial-ready release. Current validation is on the build workstation; clean-account/VM and independent nontechnical human usability remain separate verification requirements. Withdrawn GUI handler tests do not prove visual layout or human comprehension. Live auth and one bounded live task require the owner's own key/account and a fresh authorized grant, entered locally rather than supplied in chat. If Windows policy blocks unsigned code, record **WHY_INSTALLER_COULD_NOT_DO_IT: OS_UNSIGNED_APP_POLICY**; minimum action is an owner-approved signing/distribution route or the organization's allowed executable process. If a client cannot import MCP configuration, record **WHY_AI_COULD_NOT_DO_IT: CLIENT_CONFIGURATION_PERMISSION_OR_CAPABILITY**, name the client and exact failed step. No ordinary user is instructed to run Python or PowerShell as a workaround.
