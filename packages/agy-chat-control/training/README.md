# Project-local delegation candidates

Training here means contextual instruction and measured holdout behavior, not
model weight training or global AGY canon promotion. Read dated evidence and
root delta alongside historical worker cards. Worker text cannot grant tool
rights, provider credentials or independent acceptance.

`task_compiler.prepare` derives a workflow lease from current time, bounded by
mission deadline, then calls `interop_contract.validate_task`. This fixes the
observed correction-packet expiry defect without rewriting its failed history.
The caller must independently verify actual owner authority, resource eligibility,
obtain a fresh real provider grant and revalidate immediately before a single
dispatch. This helper has no network/dispatch capability; expiry metadata alone
does not authorize execution. ACK/pending/unknown operations reconcile only the
same provider operation; a generic three-attempt policy is not adopted.

The live daemon uses its separately reviewed signed 45-second claim grant. Its
14-file P1 source snapshot is unchanged by this isolated offline candidate.
Do not invoke historical example tasks against providers or refresh old accepted
missions. Run local regression with Python unittest discovery in `tests/`,
`provider-interop/` and `training/` separately. No provider is called by these tests.
