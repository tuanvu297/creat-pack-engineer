# Three product tracks

| Track | 0.1.0 working slice | Next product-specific milestone |
| --- | --- | --- |
| Release Toolkit | ZIP inspection, scanner, reproducible builder, verifier | Buyer pilot with a real authorized repo and acceptance evidence |
| AI Adapter Starter | Durable local demo, stable task identity, no blind retry | One selected provider with live auth, request IDs and reconciliation tests |
| Release Assistant software | JSON CLI QA report with package gaps | User workflow and optional UI chosen from actual operator needs |

Target users are proposed: developers shipping repos/tools, AI integrators and
operators checking handoffs. These are positioning hypotheses, not demonstrated
customer demand. Do not assign price, claim revenue or present this foundation
as three finished commercial products.

Suggested workflow: choose a real use case -> define contract and acceptance ->
implement a vertical slice -> independent local QA -> authorized provider QA if
needed -> package -> customer trial -> confirm terms -> distribution.

Roadmap checkpoints: 0.1.0 local foundation; 0.2.0 selected product pilot; 1.0.0
only after supported environments, user acceptance and commercial terms are
verified. Dates and pricing remain user decisions.
